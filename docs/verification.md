1. `ServiceController.ResetData` сначала читает оба скрипта, затем выполняет заполнение и создание триггеров
   в общей транзакции. При отсутствии файла или ошибке SQL сохраняются прежние данные и триггеры.
2. Оператор и заведующий могут повторно выдать квитанцию выбранному клиенту через историю его подписок.
   Это работает и для клиента без учётной записи.
3. Каталог перечитывается при входе, открытии оформления и изменения цены. Добавлена команда
   «Файл → Обновить данные» для изменений из другого экземпляра программы.
