# Контракт между слоями

Слой данных (база, Entity Framework Core, контроллеры, DTO) — Жариков Ярослав.
Приложение (WPF, MVVM, окна) — Сойкин Святослав.

Здесь на каждый пункт задания записано, чем приложение получает или меняет данные: метод контроллера
(имя, параметры, что возвращает), запись DTO с полями и объект базы данных. Окна пишутся по этому файлу,
слой данных реализует ровно его. Контракт меняется только через pull request, одобренный обоими.

Заполняется в первую неделю спринта 1, вместе с ER-диаграммой.

## Шаблон пункта

```
Метод:      Controller.Method(параметры) -> что возвращает
DTO:        record Имя(Поле тип, ...)
Объект БД:  представление / функция / процедура / таблица через EF Core
Ошибки:     какие исключения или сообщения получает окно
```
