## Вариант 1 — Почта

Требуется создать программную систему, предназначенную для работников почтового отделения. Такая система
должна обеспечивать хранение сведений о подписчиках газет, журналов…, обслуживаемых отделением связи,
и о почтальонах.

Каждое подписное издание характеризуется индексом, названием и подписной ценой. Данные о подписчиках
включают в себя: фамилию, имя, отчество, домашний адрес, индексы получаемых изданий, дату, начиная с которой
оформлена подписка, и срок подписки на каждое издание.

Несколько домов объединяются в участок, который обслуживается одним почтальоном. Каждый почтальон может
обслуживать несколько участков.

В БД должны содержаться сведения о том, к каким участкам относятся подписчики газет, и об обслуживающем
их почтальоне.

Заведующий почтовым отделением может принять на работу и уволить почтальона, при этом участки не должны
оставаться без обслуживания.

Оператор почтовой связи должен иметь возможность по просьбе клиента оформить подписку, а также добавить
в БД сведения о новом подписном издании.

Оформление подписки связано с выдачей клиенту квитанции, в которой указывается общая стоимость подписки,
что выписано, и на какой срок.

Возможны следующие запросы к БД:
1. Определить наименование и количество экземпляров всех изданий, получаемых отделением связи.
2. По заданному адресу определить фамилию почтальона, обслуживающего подписчика.
3. Какие газеты выписывает гражданин с указанной фамилией, именем, отчеством?
4. Сколько почтальонов работает в почтовом отделении?
5. На каком участке количество экземпляров подписных изданий максимально?
6. Каков средний срок подписки по каждому изданию?

Нужна справка о количестве подписчиков, количестве газет и количестве журналов, выписанных на текущий момент
подписчиками.

Требуется формирование отчёта о доставке почтой газет и журналов. Отчёт должен быть упорядочен по участкам.
Для каждого участка указывается фамилия и инициалы почтальона, обслуживающего участок, и перечень доставляемых
изданий (индекс и название издания, адрес доставки, срок подписки, количество экземпляров). По каждому изданию
указывается средний срок подписки и суммарное количество экземпляров, а по участку — количество различных
подписных изданий.

В отчёте должно быть указано, сколько почтальонов работает в почтовом отделении, сколько всего участков
оно обслуживает, сколько различных изданий доставляет подписчикам.

## Пояснения преподавателя на выдаче задания 09.10.2026

- Курсовой проект — прежде всего работа по проектированию: проект базы данных, требования пользователя
  и разработчика; код — после проекта.
- Работники отделения входят в программу по логину и паролю; у каждой роли свой набор команд: заведующий,
  оператор, почтальон, подписчик (видит свои подписки и их историю), гость без входа (каталог изданий,
  регистрация подписчиком). Приложение WPF работает локально с общей базой отделения.
- Хранятся сведения и о работниках отделения. Почтальон может быть и подписчиком — персональные данные общие.
- Домашний адрес хранится не одной строкой; подписки — отдельной таблицей.
- Число участков у почтальона ограничивается — ограничение выбираем сами.
- При приёме почтальона ему выделяются участки; при увольнении его участки распределяются между оставшимися
  почтальонами — программно или заведующим вручную.
- По одной подписке может быть выписано несколько экземпляров издания.
- Квитанция сохраняется в базе и выдаётся файлом (текст, XPS или PDF). Справка — отдельной формой или PDF,
  только по действующим подпискам. Отчёты — по возможности в PDF.
- Отчёт о доставке: по участкам; под каждым изданием итоговая строка — средний срок и суммарное количество
  экземпляров; по участку — число различных изданий; в конце — число почтальонов и участков.
