# Почтовое отделение

Курсовой проект по .NET, вариант 1 «Почта». Сойкин Святослав, группа ПВ521.

Программная система для работников почтового отделения: подписчики газет и журналов, подписные
издания, участки и почтальоны. Оформление подписки с выдачей квитанции, приём и увольнение почтальонов,
запросы к базе данных, справка и отчёт о доставке.

## Технологии

- C#, .NET 10, WPF, паттерн MVVM
- MS SQL Server: таблицы, представления, функции, хранимые процедуры, триггеры
- ADO.NET (хранимые процедуры) и Entity Framework Core (каталог изданий, справочники)
- QuestPDF — квитанции и отчёт о доставке в PDF

## Как запустить

1. В SSMS выполнить скрипты из `Сойкин_Святослав/Database/Scripts` по порядку:
   001 → 002 → 003 → 004 → 005 → 006 → 008.
   Скрипт 001 создаёт базу `PostOffice_Soykin_PE521`, если её нет.
2. Скрипты 007 (вызовы процедур) и 009 (проверка триггеров) меняют данные — после них заново выполнить 005 и 008.
3. Строка подключения — `Сойкин_Святослав/DataLayer/Infrastructure/Connection.cs`. Сейчас указан экземпляр `.\SQLEXPRESS`,
   для экземпляра по умолчанию — закомментированная строка с `Data Source=.`.
4. Открыть `Сойкин_Святослав/Soykin_Svyatoslav.slnx`.
   В обозревателе решения нажать правой кнопкой на проект `PostOffice` → «Назначить запускаемым проектом».
   `DataLayer` — библиотека, отдельно её запустить нельзя. Затем F5 или Ctrl+F5.
   Приложение открывается гостем: каталог изданий, вход, регистрация подписчика.
5. Учётные записи для проверки, пароль у всех `post2026`: belova — заведующий; kozlova, morozov — операторы;
   petrov, smirnova, vasiliev — почтальоны; nikolaev — почтальон и подписчик; fedorova — уволенный почтальон,
   подписчик; kuznetsov, li, ivanov, sokolova и другие — подписчики (полный список — в шапке 005).
6. Квитанции и отчёты о доставке сохраняются в PDF в папках `App_Files\Receipts` и `App_Files\Reports` рядом с exe.
7. Резервная копия: 010 создаёт `C:\Temp\PostOffice_Soykin_PE521.bak`, 011 восстанавливает базу из него.

## Документация и возможности

- [Презентация](Презентация/Почта_Сойкин_визуальная.pptx).
- «Файл → Обновить данные» перечитывает списки после изменений другого экземпляра приложения.
- «Клиенты → Квитанция клиенту...» повторно выдаёт документ по выбранной подписке, в том числе без входа под логином клиента.
- Для сборки исходников нужны .NET 10 SDK и Visual Studio с поддержкой WPF.
  Готовая публикация для Windows x64 включает среду .NET; SQL Server нужен отдельно.

## Обновление прежней базы

Перед обновлением сохранить резервную копию и закрыть приложение. Выполнить 012 → 002 → 003 → 006.
Скрипт 012 переносит входы в People, сохраняя людей и подписки. Скрипт 005 при обновлении не запускать.
Для новой базы остаётся порядок 001 → 002 → 003 → 004 → 005 → 006 → 008; 012 ей не нужен.
